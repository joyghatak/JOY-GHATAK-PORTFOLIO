Drop these two files in this folder to activate them on the site:

1. profile.jpg   -> your photo, shown in the hex frame in the hero panel
2. transition.gif -> your GitHub GIF, shown briefly in the boot-up sequence on page load

The site works fine without them (a "JG" monogram and a plain boot sequence
are used as fallbacks), so you can preview it right away and add the files
whenever you have them ready.
